    주요 공공기관 공모·입찰사업

    기업마당·K-Startup·IPET 등에서 웹 검색으로 수집한 주요 공공기관 공모·지원·입찰 프로그램만 모아 카드로 보여줍니다 ( 기준 스냅샷, 총 건).

    조건에 맞는 공모·입찰사업이 없습니다.

    이 페이지는 정기 자동수집이 아닌 수동 스냅샷입니다. 지원 전 반드시 원문 공고에서 접수기간과 마감 여부를 다시 확인하세요 — 매주 자동 수집하려면 창업진흥원(K-Startup) 등 각 기관 Open API의 서비스키가 추가로 필요합니다. 사업명을 클릭하면 원문 공고 페이지가 새 탭으로 열립니다.

    나라장터(g2b.go.kr) Open API로 매주 자동 수집된 입찰·사전규격 공고와, 기업마당·K-Startup·IPET 등에서 웹 검색으로 수집한 주요 공공기관 공모·지원사업( 기준 스냅샷)을 하나의 표로 통합했습니다. 동일 나라장터 공고가 여러 주에 걸쳐 반복 수집된 경우 공고번호·구분·게시일시 기준으로 중복을 제거해 표시합니다(수집 원본 건 → 고유 건). 모든 행은 공고명 클릭 시 실제 원문 상세페이지로 바로 이동합니다 — 나라장터는 API 응답 링크 또는 공고번호 기반 재구성 링크, 공모·지원사업은 검색으로 확인한 원문 링크입니다. 드물게 검색 표시가 남은 나라장터 건은 공고번호 형식을 인식하지 못한 예외로, 클릭 시 공고번호가 클립보드에 복사되고 나라장터 홈이 새 탭으로 열립니다. 공모·지원사업 항목은 정기 자동수집이 아니므로 지원 전 원문에서 마감 여부를 다시 확인하세요 — 이 항목도 매주 자동 수집하려면 창업진흥원(K-Startup) 등 각 기관 Open API의 서비스키가 추가로 필요합니다. 통계 페이지의 카드를 클릭하면 검색 페이지로 이동해 해당 조건이 자동 적용됩니다.
